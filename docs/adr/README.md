# ADR（Architecture Decision Records）

設計上の決定を 1 件 1 ファイルで残す。「何を決めたか」だけでなく、「なぜか」「何を採らなかったか」「何を引き受けたか」を書く。
決定を覆すときは元の ADR を消さず、状態を「置き換え（→ ADR-xxxx）」にして新しい ADR を足す。

置き場所：`docs/adr/NNNN-短い名前.md`（2026-09-26 に決定。要件定義書が参照していた `DESIGN.md（ADR）` は存在しなかったので、ここに置く。#9）

|---|---|---|---|

## 書式

```markdown
# ADR-NNNN: 題

| 項目 | 内容 |
|---|---|
| 状態 | 提案 / 採用 / 置き換え（→ ADR-xxxx） |
| 日付 | YYYY-MM-DD |
| 決めた人 | |
| 関係 | Issue、要件の番号、関連する ADR |

## 背景
## 決定
## 理由
## 採らなかった案
## 引き受けること（結果）
## 確かめ方
```
